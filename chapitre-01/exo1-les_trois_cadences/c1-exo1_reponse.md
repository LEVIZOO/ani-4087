 Exercice 1 : Les trois cadences

Formules appliquées:
Durée totale d'une image (T_total = t_ms/Hz) 
Temps restant pour le code (T_code) 

Application 

 À 72 Hertz
Durée totale d'une image : 1000 / 72 = 13,9 ms
Temps restant pour le code :13,9 ms - 8,0 ms = 5,9 ms

 À 90 Hertz
Durée totale d'une image :1000 / 90 =  11,1 ms
Temps restant pour le code :11,1 ms - 8,0 ms = 3,1 ms

 À 120 Hz
Durée totale d'une image :1000 / 120 = 8,3 ms
Temps restant pour le code :8,3 ms - 8,0 ms = 0,3 ms
